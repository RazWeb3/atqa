2種類のデータを共通モデルへ変換

document

documents[] → 1要素 = 1 PlaybackUnit

doc-1, displayText, expectedText, audioUrl
quiz

1問 → question + choices[] + explanation

q-1:question, q-1:choice:0 … q-1:explanation

選択した1ユニットのQA処理

CDNからMP3取得→ STT転写→ 期待読みを正規化→ 機械差分→ Gemini音声レビュー→ 正常 / 要確認 / 判定不能

構造的な予防

  • JSONはスキーマ検証後のみ処理
  • 音声取得先はHTTPSかつ許可ホストのみ
  • AI出力は構造化JSONを再検証
  • 秘密情報はブラウザへ送らない

明示する限界

  • ASRとGeminiが同時に補正する可能性
  • 「合格保証」ではなく誤読候補抽出
  • 音声CDN障害時は検査不能
